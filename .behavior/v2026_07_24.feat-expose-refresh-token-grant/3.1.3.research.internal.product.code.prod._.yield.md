## pattern 2 — the http exchange leaf `[EXTEND]` (mirror, do not edit)

`exchangeOidcResponseCodeForTokens` is the axios POST leg. it is the template for a new
`exchangeRefreshTokenForTokens`, but its **single-throw error branch must be upgraded** in
the new leaf (not in this file).

> [3] `src/domain.operations/exchange/exchangeOidcResponseCodeForTokens.ts:26-42`
> ```ts
>   // make the request to the endpoint
>   const response = await axios({
>     method: 'POST',
>     url: endpoint,
>     headers: {
>       'content-type': 'application/x-www-form-urlencoded',
>     },
>     data: {
>       grant_type: 'authorization_code', // https://datatracker.ietf.org/doc/html/rfc6749#section-4.1.3
>       code: oidcResponseCode,
>       ...
>     },
>     validateStatus: () => true, // dont throw for us, we will throw it ourselves, since the axios errors dont have good error messages
>   });
> ```

> [4] `src/domain.operations/exchange/exchangeOidcResponseCodeForTokens.ts:44-53`
> ```ts
>   // extract the tokens from the response data
>   if (response.status >= 300)
>     throw new UnexpectedCodePathError(
>       'unsuccessful response from oidc identity provider',
>       { status: response.status, data: response.data },
>     );
>   const { access_token: accessToken, id_token: identityToken } = response.data;
>   // return the identity and access tokens
>   return { access: accessToken, identity: identityToken };
> ```

**relation to wish**: the new refresh leaf reuses the axios shape ([3]) verbatim (POST,
form-urlencoded, `validateStatus: () => true`) but sends `grant_type: 'refresh_token'` +
`refresh_token` (+ optional `scope`/`resource`) instead of `authorization_code` + `code`.

- `[REUSE]` the axios call shape + `validateStatus: () => true` idiom ([3]).
- `[EXTEND]` the error branch ([4]): the single `UnexpectedCodePathError` for every
  `status >= 300` becomes the **three-way classification** (expired / rejected / malfunction)
  in the new leaf. the extant leaf ([4]) is **not** edited — the coarse behavior stays for the
  code grant (out of scope; vision "awkward" note).
