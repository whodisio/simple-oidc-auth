# 4.1.roadmap — getTokensFromOidcRefreshClaims

execution roadmap for the blueprint at `3.3.1.blueprint.product.yield.md`. checklist-style,
dependency-ordered (leaf-first, so every phase compiles + tests green before the next builds on
it), with behavioral acceptance criteria + a verification command at each step.

## legend

- `[ ]` unchecked step · `[x]` done
- **dep** = the prior phase(s) this step needs green first
- **verify** = the exact command that proves the step's acceptance criterion
- **read first** = briefs the builder MUST read before the phase begins

## global read-before-any-code

read once, up front — these govern every phase:

- `3.3.1.blueprint.product.yield.md` — THE blueprint (filediff tree, codepath tree, grain
  rationale, error contracts, test coverage, the harness API, deterministic-`expiresAt` strategy)
- `1.vision.yield.md` — the outcome world, the term table, the four discrimination outcomes
- `2.1.criteria.blackbox.yield.md` — the given/when/then usecases each test transcribes
- `2.2.criteria.blackbox.matrix.yield.md` — matrices A (response→error), B (success→output),
  C (request wire-shape) the tests assert exhaustively

        phase 5 (harness) ─→ phase 6 (comm integ)
                                ▼              │

                                ▼

leaf-first: every phase compiles + its own tests pass before the next depends on it, so a break
is localized to the phase that introduced it — never discovered three layers up.

## the discrimination guarantee (the through-line to verify at the end)

the whole feature exists so a caller tells the four outcomes apart from return + throw shape
alone. the roadmap proves it at three tiers: unit (`asOidcTokenError` maps each response → right
class), integration (real transport, matrices A/B), acceptance (the journey exercises all three
error families + keep-vs-rotate + retry-recovery over the shipped surface). phase 11 is not done
until a caller that follows the obvious moves cannot discard a live token on a hiccup/rate-limit,
loop on a dead one, or re-auth on a fixable request.
