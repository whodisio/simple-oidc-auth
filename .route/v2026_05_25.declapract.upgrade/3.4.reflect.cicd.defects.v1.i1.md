## defect classifications

### defect 1: invalid keyrack extends

**classification**: repo quirk

**rationale**:

this defect is specific to `simple-oidc-auth` because:

1. the repo has a partial agent installation
   - `.agent/repo=bhrain/`, `.agent/repo=bhuild/`, `.agent/repo=ehmpathy/` directories exist
   - but they only contain `.gitignore` files, not actual keyrack.yml files
   - the directories were created to preserve folder structure without full content

2. the declapract template is correct for repos with full agent installation
   - the extends pattern is valid for repos that have the complete agent role hierarchy
   - the template assumes if `.agent/repo=X/` exists, then `keyrack.yml` inside also exists
   - this is a reasonable assumption for most repos

3. no change to declapract practices is needed
   - the template works correctly for the intended use case
   - this repo is an edge case with partial installation
   - the fix (remove extends) is specific to this repo

**action**: none required. repo-specific fix was applied.
