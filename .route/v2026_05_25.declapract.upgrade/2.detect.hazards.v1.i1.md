# 2.detect.hazards — iteration 1

## hazards detected

### 1. circular dependency in helpful-errors (BLOCKER)

**what**: `helpful-errors@1.5.3` has internal circular dependency
```
helpful-errors/dist/HelpfulError.js -> helpful-errors/dist/withHelpfulError.js
```

**why breaks**: `test:lint:cycles` fails — dpdm detects cycles in node_modules

**how to verify**: `npm run test:lint:cycles`

**fix**: upgrade dev dependencies that pull in helpful-errors@1.5.3

**packages that need upgrades** (all dev deps):
- declapract-typescript-ehmpathy@0.47.69
- declastruct@1.9.1
- declastruct-github@1.4.0
- domain-objects@0.31.9 (transitive via above)

**no workaround**: user explicitly rejected pnpm overrides

### 2. type export for OidcResponseClaims (FIXED)

**what**: `src/index.ts` re-exported interface without `export type`

**why breaks**: typescript `isolatedModules` requires `export type` for type-only exports

**fix**: changed to `export type { OidcResponseClaims }`

### 3. pkg.private reference in provision (FIXED)

**what**: `provision/github.repo/resources.ts` accessed `pkg.private` which doesn't exist

**why breaks**: typescript error — property doesn't exist on package.json type

**fix**: hardcoded `visibility: 'public'` and `private: false` since this is a public package

### 4. unused dev dependencies (FIXED)

**what**: depcheck found unused packages after upgrade

**packages removed**:
- @trivago/prettier-plugin-sort-imports
- @tsconfig/node-lts-strictest
- core-js
- rhachet-roles-rhachet
- ts-jest
- ts-node
