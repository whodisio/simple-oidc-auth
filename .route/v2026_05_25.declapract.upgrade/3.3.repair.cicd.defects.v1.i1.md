# 3.3.repair.cicd.defects

## defects

### defect 1: invalid keyrack extends

**what**: CI failed with `BadRequestError: extended keyrack not found`

**how**: the `.agent/keyrack.yml` file was added with `extends` that reference files absent from this repo:
```yaml
extends:
  - .agent/repo=bhrain/role=reviewer/keyrack.yml
  - .agent/repo=bhuild/role=dispatcher/keyrack.yml
  - .agent/repo=ehmpathy/role=mechanic/keyrack.yml
```

these paths point to parent keyrack files from shared agent roles, but this repo only has `.gitignore` files in those directories.

**why**: the keyrack.yml was templated from a repo that has the full agent role hierarchy. this repo doesn't have those extended keyrack files.

**fix**: removed the invalid `extends` section from `.agent/keyrack.yml`. result:
```yaml
org: whodisio
env.prod: null
env.prep:
  - EHMPATH_BEAVER_GITHUB_TOKEN
  - FIREWORKS_API_KEY
  - EHMPATHY_SEATURTLE_GITHUB_TOKEN
  - XAI_API_KEY
env.test: null
```

## summary

| defect | root cause | fix |
|--------|-----------|-----|
| invalid keyrack extends | template assumed parent keyrack files exist | removed extends section |

## result

CI passed after fix. PR merged to main.
